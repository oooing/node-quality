# 云鉴 · 网页助手 0.2.2

支持云鉴 Windows 客户端和旧 Clash IP Web 面板，不依赖 AI。

## 安装或更新

1. 在 Chromium 浏览器打开 `chrome://extensions`，开启开发者模式。
2. 点“加载已解压的扩展程序”，选择本目录。
3. 已加载旧版时，把文件更新到原目录后，在扩展管理页点“重新加载”。

PC 客户端入口为“设置 → 自动检测 → 网页助手 → 打开文件”。首次安装后，从客户端点线路的“补充检测”：普通查询自动保存；遇验证只需完成验证，网页结果出现后会回填。扩展只处理带任务标记的 Ping0 查询页，不读取 Cookie，不处理验证码，不改变代理。

保存失败可点网页底部“重试保存”。客户端关闭或任务过期后，需要在客户端重新发起补测。

旧 Web 使用 `#clash-panel=任务号`，PC 使用 `#node-quality=任务号&port=本机端口`。任务标记放在 URL fragment，不发送给 Ping0 服务器。扩展只把该次 IP、风险值和说明发送到本机 `/api/ping0/result`，不读取客户端访问令牌。

检测历史由客户端保存。新出口 IP 与补测 IP 不同时，结果只保留在旧 IP 历史中。
