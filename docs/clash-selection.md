# Clash 换用与保存

“换用”会改变使用所选代理组的连接。自动检测、手动检测、收藏和切换正在查看的列表都不会触发换用。

## 为什么需要官方界面

只调用 Mihomo 的代理组选择接口，可以修改运行中的选择，但不等于让 Clash Verge 保存到自己的配置。客户端重启恢复保存值时，临时选择可能丢失。

云鉴让固定的 Windows UI Automation 程序操作官方控件：进入代理页、找到对应分组、过滤并精确定位线路，再执行一次选择。选择与保存由 Clash 自己完成，不依赖 AI，不按屏幕坐标点击，也不改写 Clash 的配置或安装文件。

上游实现参考：[线路选择](https://github.com/clash-verge-rev/clash-verge-rev/blob/v2.5.10/src/hooks/use-proxy-selection.ts)、[保存选择](https://github.com/clash-verge-rev/clash-verge-rev/blob/v2.5.10/src/hooks/use-record-selection.ts)。

## 一次换用会做什么

1. 确认所查看的列表关联到 Clash 当前启用的订阅；线路配置、名称与目标分组成员匹配。
2. 读取保存记录，确认当前格式能够识别；遇到未知格式，先报错，不执行选择。
3. 若当前值和保存值已经都是目标线路，直接返回已保存，不重复操作界面。
4. 否则临时显示 Clash 窗口，在唯一匹配的分组内选择目标线路。
5. 核对控制接口中的当前选择与 `profiles.yaml` 中对应订阅、分组的保存值，均一致才返回成功。
6. 恢复操作前的隐藏或最小化状态，并尝试把焦点交回原窗口。

同时只接受一个换用任务。保存失败时不会自动切换回另一条线路，也不会降级为只改内核运行状态。

## 常见结果

| 提示或情况 | 含义与处理 |
| --- | --- |
| 已换用并保存 | 当前选择与磁盘记录均已确认 |
| 线路已换用，但未确认保存 | 当前可能已经变化，请在 Clash 中重新选择以确认保存；不能据此承诺重启后保留 |
| 保存格式暂不兼容 | 在操作前检测到不识别的保存结构，请暂时在 Clash 中换用 |
| 未找到目标线路、同名选项不明确 | 没有确定可操作的唯一目标；请检查客户端界面和线路名称 |
| 当前查看的列表不是 Clash 正在使用的列表 | 可以检测，但需先在 Clash 启用对应订阅，才能从云鉴换用 |

## 升级兼容边界

组件识别标准用户数据目录中的 Clash Verge Rev，不锁定 `2.5.10` 等具体版本号。新增无关配置字段、调整颜色等不改变所需控件与保存结构的更新，可以沿用同一流程。

这不是自动适配任意界面的系统。如果未来官方改变控件、启动接口、配置目录或保存语义，仍可能需要更新云鉴。每次换用后的保存核对用于发现失败，不能替代对尚未发布版本的重启测试。

自动检测和手动检测都使用独立检测内核。软件启动、后台检查、查看别的列表不会为了测试兼容性而切换用户的线路。

## 开发与验证

- `windows-helper/ClashSelect.cs`：官方控件定位与调用。生产构建只开放 `select`；实验模式只能定位隔离构建。
- `backend/official_selection.py`：保存结构预检、执行组件、核对当前值与保存值。
- `backend/clash_control.py`：列表关联、配置匹配、目标分组与请求串行处理。
- `scripts/build-clash-helper.ps1`：使用 Windows 已安装的 .NET Framework 编译器构建组件；`build.ps1` 自动调用。
- `tests/test_integrations.py`、`tests/test_selection_compatibility.py`：模拟控制器与保存文件，覆盖成功、部分失败、未知保存格式和无临时切换降级。
- `tests/acceptance_control.py`：仅启动独立 Mihomo，验证没有受支持官方界面时拒绝换用，不操作正式客户端。

完整的官方重启验收应在独立 Windows 测试环境中进行：关闭系统代理、TUN 和自启，使用独立配置与内核，验证选择、落盘、正常退出、重新启动后恢复。不能仅复制 Clash 的 exe 就认为配置与服务已经隔离。

当前完成的实际验收基于 Clash Verge Rev 2.5.10，包含列表折叠、过滤、两个代理组，以及隐藏、最小化和首页状态。最终兼容性改动通过了三次云鉴接口到官方程序的保存/重启验证。测试未重启用户的正式 Clash 或整台电脑；私人原始记录与隔离工具链已经清理。
